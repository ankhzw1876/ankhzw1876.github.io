# Pixel icon sources

Six XiaHua OS app glyphs are adapted from the free Base set in
[Pixelarticons](https://github.com/halfmage/pixelarticons), licensed under MIT.

Mapping:

- `about.svg` ← `user.svg`
- `writing.svg` ← `article.svg`
- `github.svg` ← `terminal.svg`
- `xiaohongshu.svg` ← `camera.svg`
- `contact.svg` ← `mail.svg`
- `archive.svg` ← `archive.svg`

Project changes: fixed the display color to the XiaHua OS paper token, added
`shape-rendering="crispEdges"`, and kept only the six glyphs used by the site.

`game.svg` and `sakura.svg` are original project-specific 24×24 pixel glyphs.
The sakura glyph combines blossom, trunk and checker-ground pixels so the
warm-spring window stays recognizable in the taskbar and compact views.
