# URL Worlds

把一个网页链接变成一片可以旋转观察的真实 3D 风景。从正上方看，同一片风景直接投影成可扫描二维码。

当前版本为 2026-09-10 的 URL Worlds。保留 `experiments/qr-skyline/` 目录和访问地址，兼容旧版 URL City 的链接。

## 30 秒体验路径

1. 输入 HTTP(S) 链接；省略协议时会自动补全 `https://`。
2. 点击“生成风景”，选择城市、树林、山地、雪地、沙漠或塔楼。
3. 拖动画面、调整视角，或开启自动环绕。
4. 点击“俯视扫码”或画面，观察相机转到正上方，再用扫码工具打开链接。

## 风景如何直接成为二维码

二维码的每个模块对应世界坐标 XZ 平面中的一个固定方格。场景的三维高度可以不同，但俯视投影保留原始 QR 矩阵的深浅关系和四模块静区。

| 场景 | 立体表达 | 俯视时保留的规则 |
| --- | --- | --- |
| 城市 | 楼群、屋顶与立面窗户 | 深色楼顶覆盖黑格，窗户只在垂直立面 |
| 树林 | 分层树冠与树干 | 树冠的方形投影覆盖黑格 |
| 山地 | 连续起伏的山脊 | 地形高度变化，网格深浅不变 |
| 雪地 | 浅色雪地与深色岩面 | 保持高对比度网格，不用白色雪帽遮掉黑格 |
| 沙漠 | 连续沙丘 | 浅沙与深色地块分别保留白格、黑格 |
| 塔楼 | 层叠塔身和塔顶 | 所有塔层都位于各自黑格的投影范围内 |

同一链接、同一场景的观察过程中，几何顶点和颜色保持不变。正交相机改变方向和取景范围，最终从正上方看到原矩阵；不会把楼群打碎、重新排列模块或盖上一张独立二维码。更换链接或场景才重新生成几何。

## 技术与运行方式

- 原生 HTML、CSS、JavaScript，Three.js 0.160.1 提供 WebGL 真实 3D 渲染。
- `qrcode-generator` 1.4.4 提供 M 级纠错、UTF-8 字节编码的 QR 矩阵。
- 两个依赖均保存在本地 `vendor/`，零构建、无服务端；直接打开 `index.html` 的 `file://` 地址即可运行，也可作为静态站点或主页 iframe 加载。
- 只接受 HTTP(S)。输入框限制 512 个键入字符，URL 规范化后限制 1,800 个字符；非法协议、无效 URL 和超过容量的输入会显示提示。
- 同一规范化 URL 和同一场景在当前算法版本中生成相同结构。
- 高密度二维码省略城市窗户细节，塔楼最多三层，控制几何规模。
- 无 WebGL 时降级显示标准二维码；减少动态效果设置下直接切换视角终态，不自动环绕。
- 页面不可见或父播放器隐藏时暂停渲染，恢复可见后继续。

## 当前版本验证记录

2026-09-10 已完成：

- 默认主页 URL 的六种场景，在桌面、390×844 和 320×700 视口均通过 Chromium `BarcodeDetector` 自动解码。
- 上述手机视口没有横向溢出。
- 中文和 emoji 链接的解码结果与规范化 URL 一致。
- `javascript:` 等非法协议被拒绝，主机加端口的输入可正确补全协议。
- 同一场景的几何 `positions` 和 `colors` 校验和，在斜视与俯视之间完全一致。
- 153×153 长中文 URL 的六种场景，在 320×700、DPR 1 下均通过自动解码；俯视取景同时对齐整数物理像素的模块大小与原点。

- 主页 iframe 在 1440×900 桌面父视口与 320×700 手机父视口下可正确扫码，手机内页无横向溢出。
- 返回文件夹暂停渲染并把焦点归还给 URL Worlds 卡片；再次打开恢复；关闭窗口卸载 iframe。
- 拖动旋转与自动环绕可用；系统减少动态效果设置下立即切换到俯视终态。
- 模拟 WebGL 上下文丢失后，4 秒未恢复会转为标准二维码，降级画面通过自动解码。

实体手机相机实扫仍待单独完成。浏览器自动解码不等于实体手机实扫。

## 旧版记录

2026-09-09 的 URL City v1 使用 Canvas 2D 绘制 2.5D 城市，一列 QR 对应一栋楼，黑格对应窗灯，再把窗灯重新排列成二维码。该机制已由当前真实 3D 投影实现替换。

v1 的高密度链接、iframe 和手机尺寸解码记录仅适用于旧实现，不作为 URL Worlds 当前版本的测试结论。
