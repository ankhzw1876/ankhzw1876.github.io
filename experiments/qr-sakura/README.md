# 二维码微缩世界

输入一个网页链接，让它长成樱花树、浮空群岛、月球基地或微缩书城。点击画面，镜头转向俯视，微缩景观收束成同一链接的彩色二维码；再次点击回到立体景观。

这是对[小红书参考视频](https://www.xiaohongshu.com/explore/6a9538da000000001f004395)的视觉与交互复刻研究，基于 MIT 许可的 [Every QR Code](https://github.com/AlbertAZ1992/every-qrcode) 改造。没有证据确认该仓库就是视频作者使用的源码，也不承诺逐像素一致。

## 体验方式

1. 从 XiaHua OS 的游戏文件夹打开第二项，或单独访问本目录的 `index.html`。
2. 输入 HTTP(S) 链接，点击“生成”；省略协议时自动补全 `https://`。
3. 在顶部选择「樱花树」「浮空群岛」「月球基地」「微缩书城」。切换世界只替换确定性几何，不重算链接或二维码矩阵。
4. 点击画面或“二维码”按钮，待变换结束后扫码。画面也支持 Enter、Space 切换，Escape 返回立体景观。
5. 顶部可切换「夜樱」「月白」「暖春」。默认夜樱；配色和世界选择保存在当前浏览器，切换不改变链接或二维码矩阵。
6. 立体景观中按住鼠标或用单指拖拽：左右可连续环绕 360°，上下跟随手势调整俯仰。松手后用 480ms 平滑回到初始视角；点击「复位」立即复位。画面聚焦后方向键也可旋转，R 复位。

主页的「暖春樱花树」是一个独立 XiaHua OS 窗口，从桌面图标单击打开，可最小化，也可用左侧圆点或右上角关闭。它使用 `?embed=1&palette=spring&world=sakura&qr=profile` 启动；`palette`、`world` 和 `qr` 都是白名单预设，不接受任意图片路径。`qr=profile` 同时把树形模型的内部 URL 设为用户提供二维码解出的微信入口，只在该嵌入式暖春樱花组合下生效。非前台或最小化时暂停渲染，关闭窗口后卸载 iframe 并释放 WebGPU 资源。

拖拽与轻点分开判定，移出画面再松手也会复位，不会误切二维码。扫码视角固定正俯视，拖动和方向键在二维码及镜头过渡中不改变相机；回位中切到二维码会先结束回位，避免两段镜头动画相互干扰。生成新链接重置视角，切换配色不重置视角。没有添加惯性、自转或新的粒子效果。

配色由 `themes.js` 统一驱动页面、花瓣、草地、地砖和彩色二维码。夜樱使用深靛底与雾粉花；月白使用冷灰底与蓝紫花；暖春使用奶杏底与杏色花。扫码状态保留浅色纸底和四模块宽的外围静区，无 WebGPU 时也保持标准深色二维码，不使用反色二维码。

四个世界共用同一块 QR 基础层。樱花树保留弯曲主干、分叉枝条与花簇；浮空群岛由五座岩岛、瀑布、小屋和吊桥组成；月球基地包含圆顶舱、太阳能翼、通讯塔、陨石坑与小车；微缩书城包含三面书架、中央书桌、台灯和散落书册。链接的确定性种子改变各世界的细节，同一规范化链接在同一版本下保持可复现。

这里采用镜头移动与模型形态、材质变换共同完成的过渡。不能沿用旧 URL Worlds 的“模型固定、只转相机”描述。普通独立页与游戏文件夹入口的 WebGPU 路径不用独立二维码遮盖树景；仅主页 `qr=profile` 预设在模型变形进度到达终点后，用用户给定的 430×430 原图完成最后的可扫码交接。最小化、失去前台或逆向变回树景会立即撤下原图，避免 CSS 时钟与暂停的 GPU 动画失步。

## 技术与限制

- 页面使用原生 HTML、CSS、JavaScript。改造后的 WebGPU 引擎、QR 编码器与 URL 解析依赖均打包在本地 `vendor/sakura-engine.js`，运行时不依赖 CDN、服务端或外部模型素材；链接在浏览器本地处理。
- 完整 3D 效果需要 HTTPS 或 localhost，以及可用的 WebGPU 适配器。通过静态服务器预览即可；页面运行不需要构建，修改引擎源码后才需要重新打包。
- WebGPU 不可用、初始化失败或设备丢失时，降级保留浅底深色的标准二维码，不伪装成立体树景。引擎未加载时另有旧版 QR 编码器兜底。
- 输入框最多键入 512 个字符，规范化 URL 最多 1,800 个字符；完整引擎另外受上游 QR profile 的 version 6 上限约束，实际容量取决于编码内容，远非保证支持 1,800 字符。超容量会提示使用短链接。仅接受 HTTP(S)，拒绝含账号密码的链接。
- `prefers-reduced-motion` 下冻结环境动画，并直接到达切换终态，拖拽仍可操作，松手立即复位。页面不可见、舞台离开可见区域或收到同源父播放器的隐藏通知时结束回位并暂停渲染；恢复可见后继续。
- 通用生成器仍是游戏文件夹的第二项；顶层「暖春樱花树」只是同一引擎的定制展示窗口。六场景版仍完整保留在 `../qr-skyline/`，可从本页页脚“六种风景旧版”进入。
- 暖春樱花树在桌面和手机上都是按需打开的 OS 应用；未打开、非前台、最小化或关闭状态不运行 WebGPU。

## 构建与验证

引擎源码、锁定依赖、重建命令和 `verify.mjs` 位于 [engine-src/README.md](engine-src/README.md)。自动检查覆盖确定性、有限数值缓冲区、标准 QR 几何、非法协议与超容量输入、暂停及减少动态效果等生命周期规则。无 GPU 的脚本验证不能代替浏览器中的着色器编译、视觉和扫码检查。

在本目录运行 `node verify-themes.mjs`，可检查三套主题的 GPU 色值、文字对比度、浅色二维码纸底、关闭粒子特效、偏好存储与存储被禁用时的行为。
运行 `node verify-orbit.mjs` 检查旋转、世界切换、二维码视角锁定、键盘/复位与渲染生命周期；运行 `node verify-worlds.mjs` 检查四世界的确定性、数值边界、URL 差异、二维码基础层不变和装饰提前淡出规则。真实渲染和触摸仍需浏览器检查。

- 配色更新：三主题在 1200×900 桌面与 390×844 手机视口通过截图解码；切色不重建模型、不改变 QR 矩阵；已检查刷新记忆、减少动态效果和无 WebGPU 的三主题降级扫码。
- WebGPU 模式真实截图在桌面和 320×700 窄屏下通过原生 `BarcodeDetector` 解码；包含主页链接、中文与 emoji 路径、41×41 高密度矩阵。390×844 布局无横向溢出。

- 真实浏览器中未捕获到页面错误或未处理的 Promise 拒绝，引擎 `verify.mjs` 通过。

旧六场景版的设备、长链接和 iframe 测试结果不自动适用于本版；实体手机相机实扫仍需独立验证，浏览器自动解码不等于实体实扫，也不代表所有浏览器都支持 WebGPU。
